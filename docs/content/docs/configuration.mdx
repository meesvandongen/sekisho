Sekisho reads a single JSON object, at most 1 MiB, passed with `-config`. Unknown or duplicate fields are rejected, and relative file paths are resolved against the config file's directory. A complete example lives in [`gateway/examples/config.json`](https://github.com/meesvandongen/sekisho/blob/main/gateway/examples/config.json).

## Top level

<TypeTable
  type={{
    listen: { type: 'string', default: '":8080"', description: 'Listen address.' },
    openapi_file: { type: 'string', required: true, description: 'Path to the OpenAPI 3 document used as the route allowlist.' },
    upstream_url: { type: 'string', required: true, description: 'Absolute HTTP(S) URL of the upstream, without a query. Its path is prefixed to forwarded requests.' },
    max_header_bytes: { type: 'integer', default: '32768', description: 'Maximum inbound and response header size.' },
    max_body_bytes: { type: 'integer', default: '1048576', description: 'Maximum request body size.' },
    max_concurrent_requests: { type: 'integer', default: '64', description: 'Maximum number of in-flight requests.' },
    oidc: { type: 'object', required: true, description: 'Inbound JWT verification.' },
    backend_auth: { type: 'object', description: 'The "default" backend credential.' },
    backend_auth_profiles: { type: 'Record<string, object>', description: 'Named backend credentials (at most 64). "default" and "none" are reserved names.' },
    identity: { type: 'object', description: 'Optional userinfo and introspection endpoints.' },
    policy: { type: 'object', required: true, description: 'Rule definitions, shared values and route bindings.' },
    audit: { type: 'object', description: 'Structured audit logging.' },
  }}
/>

### Rule

Exactly one of:

<TypeTable
  type={{
    cel: { type: 'string', description: 'Inline CEL expression.' },
    file: { type: 'string', description: 'CEL file relative to the config (≤ 64 KiB).' },
    ref: { type: 'string', description: 'Name of a rule in definitions. May be combined with params.' },
    all: { type: 'Rule[]', description: 'All children must be true.' },
    any: { type: 'Rule[]', description: 'At least one child must be true.' },
    not: { type: 'Rule', description: 'Negation.' },
  }}
/>

### Route

<TypeTable
  type={{

    match: { type: '{ operation_id } | { path, method }', required: true, description: 'Selects one OpenAPI operation.' },
